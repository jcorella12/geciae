# Bienvenido al manual del ERP GECIAE

Este manual te ayuda a aprovechar al máximo el sistema. Está organizado por **a quién va dirigido cada apartado**, no por módulo. Empieza por la sección de tu rol y vuelve aquí cuando necesites consultar algo específico.

> **Tip**: usa la búsqueda arriba (o el atajo `⌘K` / `Ctrl+K`) para encontrar rápido lo que buscas.

## Cómo navegar el sistema

El sistema tiene varios espacios diferenciados:

- **Mi Día**: tu tablero personal con lo pendiente del día
- **Mi Espacio** (modo simple): vista compacta para empleados de campo
- **Dashboard**: KPIs ejecutivos
- **Portal Empleado**: tu compensación, vehículo, capacitación
- **Notificaciones** (campana arriba): avisos importantes
- **Configuración**: solo CEO/director/contralor

Si en algún momento te pierdes, usa el atajo `⌘K` (Mac) o `Ctrl+K` (Windows) para abrir la búsqueda global desde cualquier lado.

## ¿Algo no funciona como esperas?

Tienes dos canales:

1. **Botón "Sugerir mejora"**: en la parte de abajo de cada página, abre un formulario para reportar a CEO/admin
2. **Soporte**: ve a [Soporte → Tickets](/soporte/tickets) y abre un ticket

Anthropic mantiene este manual actualizado conforme el sistema evoluciona. Si encuentras información desactualizada, repórtala como sugerencia y lo arreglamos.
